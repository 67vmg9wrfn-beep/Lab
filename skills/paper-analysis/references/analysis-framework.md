# Analysis Framework (Canonical)

Use the same dimensions for every paper.

## A. Metadata

- Paper ID
- Title
- Authors
- Venue
- Year
- Task domain

## B. Problem and Contribution

- Problem statement clarity (1-5)
- Main contribution type (method / dataset / benchmark / theory / system)
- Claimed novelty (short text)

## C. Methodological Rigor

- Experimental design quality (1-5)
- Baseline adequacy (1-5)
- Ablation completeness (1-5)
- Statistical reporting quality (1-5)

## D. Evidence Strength

- Dataset suitability (1-5)
- Metric appropriateness (1-5)
- Result significance/support (1-5)
- External validity/generalization (1-5)

## E. Reproducibility

- Code availability (yes/no/partial)
- Data availability (yes/no/partial)
- Hyperparameter detail (1-5)
- Compute/training detail (1-5)

## F. Practical Value

- Real-world relevance (1-5)
- Efficiency/cost awareness (1-5)
- Deployment feasibility (1-5)

## G. Risk and Limitations

- Reported limitations (short list)
- Unreported but likely limitations (short list, mark as inference)
- Bias/safety/fairness concerns (short list)

## H. Standard Output Snippets

- 3-line executive summary
- 3 strongest findings
- 3 highest-priority caveats

## Scoring Note

Scores are comparative aids, not objective truth. Always include text evidence.
